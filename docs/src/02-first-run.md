Fifteen minutes, in this order. Each step is visible on the site immediately.

## 1. Brand

**Settings → Design → Brand**

- **Accent colour** — the theme uses exactly one, and rations it: it marks what
  is live, new, or under the cursor. Pick something that survives on both white
  and near-black. The theme's own default is a vermilion, `#f04e2e`.
- **Publication icon** — becomes the favicon.
- **Logo** — optional. Without one the theme sets your site title in the display
  face beside a small accent dot, which is a designed state rather than a
  fallback. Try it before uploading anything.

## 2. Navigation

**Settings → Navigation**

Primary navigation appears in the header and the mobile drawer. Secondary
appears in the footer. Four or five primary items is the practical limit before
the header starts competing with your logo.

## 3. Theme settings

**Settings → Design → Site-wide / Homepage / Post**

Sixteen settings, all documented in the [settings reference](#settings). The
four worth setting deliberately on day one:

- **Homepage layout** — Call Sheet, Stacked or Grid
- **Homepage lead** — what fills the large slot at the top
- **Post layout** — the default for every post
- **Typeface pairing** — the display face for headlines

## 4. Feature images

The theme frames every feature image with a viewfinder bracket and crops it to
the ratio you choose in **Post → Feature image ratio**. 16:9 is the default.

A post without a feature image is fine — the layouts are built for it. In lists
the media slot either fills with a hairline hatch or steps out of the way,
depending on the layout, so a page of image-less posts still looks deliberate.

## 5. Members

If you have memberships on, the theme shows a Subscribe button in the header and
a newsletter band on the homepage. If you do not, neither appears — there is no
setting to turn off, and nothing to hide.
